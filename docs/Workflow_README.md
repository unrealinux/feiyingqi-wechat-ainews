# 龙虾类 AI Agent 横向测评工作流（简要说明）

本工作流用于迭代生成适合公众号发布的横向测评文章。核心步骤：从模板出发，填充数据、检查事实、生成 Markdown 与 HTML 版本，并可直接提交草稿与发布。 

步骤要点
- 填充真实数据与来源：逐条完成对比维度、场景匹配和决策树。
- 生成两种版本：Markdown 草稿与 HTML 页面，用于不同编辑场景。
- 更新元数据：标题、摘要、封面和关键词。
- 进行事实核查：标注需要核实的数据点及首选来源。
- 发布前验证：确保无未授权信息、冲突或版权问题。

产出产物
- docs/lobster_cross_eval_template_v3.md（完整草稿文本）
- docs/lobster_cross_eval_template_v3.html（HTML 版本）
- 相关文章的引用链接列表与数据表格模板

后续动作
- 根据需要，将草稿内容合并到 publish_article.py 的工作流中，自动化生成草稿并推送到公众号草稿箱。 
- 如需，请告知我继续填充具体数据与撰写正文段落。
